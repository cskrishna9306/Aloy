# Aloy
Wakes up, checks my TODOs, tells me what matters. An Alexa skill + LLM summarizer for daily goals.

### Why "Aloy"?

Named after the protagonist from one of my favorite PS exclusive games, **Horizon: Zero Dawn**! I loveddd the setting of this game in a post-apocalyptic universe where autonomous machines have gone haywire, and Aloy, the MC, is set out to tame this metal wilderness w/ a bow and arrow! Does not really align w/ the intent of this project but whatever since I'm running out of project names and seem to be inspired by her while creating this repo haha!
